# MoQ Pro Provider

Manage [MoQ Pro](https://moq.pro) CDN resources through its `/v1` [management API](https://moq.pro/doc/api): projects, the signing keys that mint media tokens, recording rules, and sync targets, with usage and recordings as data sources. Works with Terraform and OpenTofu.

Create a **write** account token with access to all projects in [account settings](https://moq.pro/settings/tokens) and export it as `MOQ_TOKEN`. Point `MOQ_ENDPOINT` at another `/v1` base, such as staging, to manage that environment instead.

```terraform
terraform {
  required_providers {
    moq = {
      source = "moq-dev/moq"
    }
  }
}

# Reads the account token from MOQ_TOKEN. Set MOQ_ENDPOINT, or endpoint here,
# for anything but production.
provider "moq" {}
```

## Quickstart

Create a project and a signing key that mints publish and watch tokens. This is the [quickstart](https://moq.pro/doc/quickstart)'s Terraform section:

```terraform
terraform {
  required_providers {
    moq = {
      source = "moq-dev/moq"
    }
  }
}

provider "moq" {}

resource "moq_project" "app" {}

resource "moq_signing_key" "publish" {
  project_id = moq_project.app.id
  algorithm  = "HS256"
  label      = "Quickstart"
}

output "project_id" {
  value = moq_project.app.id
}

output "key_id" {
  value = moq_signing_key.publish.id
}
```

The quickstart continues from `project_id` and `key_id` to a live broadcast.

## Behavior

- Every create sends an `Idempotency-Key`, so a create retried after a dropped connection makes one resource.
- Transient failures (rate limits, timeouts, and 5xx responses on requests safe to repeat) retry with capped exponential backoff, honoring `Retry-After`. Everything else fails at once.
- Write-only secrets (bucket credentials, sync target publish URLs) are never read back. After `terraform import`, the next apply records them from configuration.

### Optional

- `endpoint` (String) API base URL including `/v1`. Defaults to the `MOQ_ENDPOINT` environment variable, then `https://api.moq.pro/v1`.
- `token` (String, Sensitive) Account API token (`moqpro_...`) from [account settings](https://moq.pro/settings/tokens). Managing resources needs a `write` token; creating projects needs one with access to all projects. Defaults to the `MOQ_TOKEN` environment variable.
